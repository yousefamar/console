# Isolated SPA verification

Moved out of `CLAUDE.md` on 2026-09-08 (the CLAUDE.md diet, ^rosy-owl) — the text below is the trimmed reference that used to load into every request. The CLAUDE.md stanza for this subsystem keeps only the cross-cutting invariants; treat THIS file as the authoritative detail and keep it current the way you would CLAUDE.md.

**Isolated SPA verification from a worktree (never Yousef's live tab)**: `npx vite --config vite.verify.config.ts --port 5174` serves the worktree's SPA with a Caddy-like `/hub` proxy to the live hub that injects the local `cli` bearer on HTTP + WS upgrades and strips `Origin` (the hub's WS Origin allow-list would 401 `localhost:5174`). Drive it with Playwright (resolve from `~/proj/code/astera-app/node_modules/playwright/index.mjs`, `ignoreHTTPSErrors`): `page.route('**/hub/auth/session', fulfil {authenticated:true})` opens `GatedBoot` (that probe is cookie-only — a bearer can't satisfy it), everything else is real hub data. Use `waitUntil:'load'` (WS/polling never reach `networkidle`); a fresh page's `import('/src/store/x.ts')` IS the app's instance (the trap above is HMR-churn only). Inject fake store state via `setState` to exercise UI branches the live hub can't produce yet — a live `refreshSpaces` may race and replace it, so set everything a branch needs in ONE `setState`. Symlink `node_modules` (root + `server/` + `cli/`) from the main checkout instead of reinstalling. Built for ^pale-tern; nothing here touches the user's session. **Dictation in headless Chromium (^lime-newt)**: `webkitSpeechRecognition` neither transcribes nor errors, so `useDictation` never falls back — `addInitScript` setting `localStorage['console:dictation:hubOnly']='1'` takes the hub path Brave takes; and `--use-file-for-fake-audio-capture=<wav>` reaches the hub `/stt` relay but OpenAI transcribed nothing from it, so mock the relay with `page.routeWebSocket(/\/hub\/stt/, …)` sending `{type:'interim',text}` deltas + a `{type:'final'}` on `done` — deterministic, zero OpenAI minutes. Don't anchor locators on a textarea placeholder that changes while recording ("Listening…"). **A recurring writer (^neat-duck)**: `sessions`/board lists aren't a one-off race like `refreshSpaces` — the live hub keeps pushing real `session_list`/WS updates on an interval, so a single injecting `setState` can get silently evicted seconds later. Re-assert in a poll loop (re-run the `setState`, wait ~150ms, check the target element, repeat up to ~20×) until it sticks, then screenshot immediately — don't assume one injection survives long enough to interact with. **Inject the PANE too (^loud-lynx)**: panes mount lazily, so store state for a pane the fresh page never opened renders nothing at all (zero cards, which reads exactly like a broken feature) — call `useUiStore.getState().setActivePane('<pane>')` in the same `setState` block and assert `activePane` in the poll's success check. Same class for transcripts (^ripe-crab): a brand-new FAKE session injected into `useAgentStore` renders nothing on Spaces (the pane only shows sessions it can place in a space) — append the probe message to a REAL session's `messagesBySession` instead, then `selectSpace('console')` + `selectSession(realId)` + `setActivePane('spaces')` in the same poll iteration. **Calendar pane in the verify SPA**: it gates on `isSignedIn()` (`src/gmail/auth.ts`), hydrated from `/auth/status` with a 4 s abort — against a just-restarted hub that times out and a fresh browser has no cached flag, so the pane shows "Sign in with Google"; seed `localStorage.gmail_signed_in='1'` via `addInitScript` (^wise-stag).

**Screenshotting the SPA from a fork worktree (^fond-yak recipe).** The gate needs a hub session, the hub is HTTPS on 9877, and cross-origin fetches/WS die on CORS and `ws-origin-not-allowed`, so a bare `vite --port N` shows only "Sign in with Google". Run Vite with a TEMP config (`vite --config vite.tmp.config.ts`, never committed) that `mergeConfig`s the repo config with `server.proxy["/hub"] = { target: "https://localhost:9877", secure: false, ws: true, rewrite: strip /hub, bypass: answer GET /hub/auth/session with {authenticated:true} (the probe is cookie-only), configure: on proxyReq/proxyReqWs remove `cookie`, remove `origin`, set `authorization: Bearer <cli token from ~/.config/console/local-tokens.json>` }`. The SPA then runs same-origin against the live hub as the CLI principal — read-only unless you click something that writes, so never press Approve/Done on a real card for a screenshot. Playwright is installed globally (`$(npm root -g)/playwright/index.mjs`). Kill Vite by pid from `ss -tlnp` — a `pkill -f` pattern that matches your own shell command kills the shell (exit 144).
